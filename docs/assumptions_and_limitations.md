# Assumptions and limitations

- Historical, anonymised sample from 2016–2018; actual range is derived from the data at run time. Not current performance.
- No cost, margin or profit data: no profit/CLV/savings claims are made.
- Reviews are voluntary; review KPIs describe reviewers only.
- `customer_unique_id` assumed to identify a person; repeat purchasing only observable inside the window.
- Dominant-category assignment (highest-priced item) is a simplification for order-level views.
- Small sellers/segments are suppressed (<30 orders) rather than ranked.
- Findings are associations; no causal inference.
- Tests use SYNTHETIC fixtures; real-data execution is documented in `data_quality_report.md` status.
