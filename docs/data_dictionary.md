# Data dictionary

Source tables used (Olist public dataset): customers, orders, order_items, order_payments, order_reviews, products, sellers, product_category_name_translation. Required columns are listed in `src/config.py` (`REQUIRED_FILES`). The geolocation table is not used. See the Kaggle page for official column descriptions. Derived columns are described in `kpi_dictionary.md` and `methodology.md`.
