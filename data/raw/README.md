# Raw data (not committed)

Download the Olist Brazilian E-Commerce dataset and place these 8 CSVs here:
`olist_customers_dataset.csv`, `olist_orders_dataset.csv`, `olist_order_items_dataset.csv`,
`olist_order_payments_dataset.csv`, `olist_order_reviews_dataset.csv`, `olist_products_dataset.csv`,
`olist_sellers_dataset.csv`, `product_category_name_translation.csv`
(`olist_geolocation_dataset.csv` is not used.)

**Manual:** https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce -> Download -> unzip here.
**CLI:** `pip install kaggle`, put your token in `~/.kaggle/kaggle.json`, then `make data`.
